# ConvoyMates — Release Notes

**Journey Creation & Tracking**
- Start a journey by searching for a destination with live autocomplete or long-pressing the map to drop a pin
- Invite your group with a 6-character journey code or a scannable QR code
- Live shared map shows every member's name, avatar color, and real-time distance to the destination
- Creators can end a journey for everyone; members can leave at any time
- Journey History tracks every past journey — destination, stops, your role, and start/end times — synced to your account so it's preserved across reinstalls; expand any entry to see its full route, or repeat it as a new journey

**Live Location Sharing**
- Foreground location tracking works immediately with no special permission needed
- Optional "Always Allow" background tracking keeps your position updating for the group even while using another app like Maps
- Background access is requested contextually — only when starting or joining a journey, never upfront, and easy to skip
- A persistent "Journey in progress" notification stays visible the entire time background tracking is active
- Location is never read outside an active journey, and stops the instant you leave or end one

**Sharing**
- Share your journey's QR code and code together as a single image + message via the native share sheet
- Shared messages include a Play Store link so new users can download ConvoyMates directly

**Personalization**
- Switch between Light, Dark, or System appearance at any time
- Edit your display name so your group always recognizes you
- A 3-step illustrated walkthrough introduces how journeys work on first launch

**Settings & Support**
- Rate ConvoyMates on the Play Store directly from Settings
- Contact support with one tap via a pre-filled email
- In-app prompts notify you automatically when a new version is available
- Current app version is always visible in Settings

**Privacy**
- No accounts or login — just a display name, nothing else to set up
- The app may show ads via Google AdMob to support free availability; ad display is controlled remotely and isn't always on. No other analytics or tracking SDKs are used
- Full privacy policy available in-app and on GitHub
